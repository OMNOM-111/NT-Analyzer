Платформа управляет только уже существующими strategy instances в NinjaTrader.
Автоматическое создание нового instance не поддерживается NinjaTrader AddOn API.

Рабочий процесс:
1. Добавьте стратегию вручную в NinjaTrader → Strategies tab → Add.
2. Она появится в таблице выше — выберите строку.
3. Платформа проверит параметры и начнёт мониторинг.
4. Кнопка «Включить / Остановить» управляет этим instance.

Live аккаунты отображаются только для мониторинга; команды включения и остановки для них заблокированы.
