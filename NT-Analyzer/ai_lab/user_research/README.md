# User Research Folder

Эта папка предназначена для ваших личных материалов, идей, наблюдений и исследований по разработке стратегий.

Сюда можно складывать:

- markdown-файлы;
- txt-заметки;
- csv/json со сводками;
- постмортемы;
- списки идей;
- наблюдения по инструментам;
- объяснения, почему старые стратегии были неудачны;
- разборы mismatch между backtest и demo;
- любые дополнительные материалы, которые AI должен учитывать.

## Главный контракт

AI Strategy Lab обязан:

- перед каждым новым циклом разработки читать все новые файлы в этой папке;
- перечитывать измененные файлы;
- выделять из них lessons, warnings, hypotheses и anti-patterns;
- учитывать эти материалы перед генерацией новой стратегии;
- не игнорировать свежие пользовательские исследования.

## Рекомендуемая структура

```text
ai_lab/
  user_research/
    README.md
    incoming/
    curated/
    postmortems/
```

## Назначение подпапок

- `incoming/` — новые файлы от пользователя, которые AI еще не переработал.
- `curated/` — материалы, которые уже признаны полезными и часто должны участвовать в retrieval.
- `postmortems/` — важные разборы провалов, технических ошибок и demo mismatch.

## Правило приоритета

Если новые файлы в этой папке противоречат старым AI-выводам, AI должен отдавать приоритет более свежему пользовательскому вводу и записывать это в свои lessons/error registries.
