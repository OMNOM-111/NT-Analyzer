# Connector 0.4.5 - Устойчивая идентичность снимка каталога

Release summary: Все страницы одной доставки каталога получают один `catalog_id`, вычисленный от содержимого, и отдаются из одного кэшированного снимка. Раньше идентичность включала отметку времени, вычисляемую на каждый запрос страницы, поэтому многостраничная доставка не могла завершиться.
Release PRs: #275
Affected subsystems: Connector bridge (CatalogWriter)
Release impact: Connector-only. Серверные контракты, Backtest, транспорт и подпись не менялись.

## Дефект

`ComputeCatalogId` смешивал в идентичность `generatedAt`, а тот вычислялся заново на каждый запрос страницы. Страница 0 приходила с одним `catalog_id`, страница 1 - с другим, сервер считал это новым снимком, сбрасывал staging и снова просил страницу 0. Повтор попадал в `UNIQUE (workspace_id, idempotency_key)` таблицы команд, и Connector получал `storage_constraint`:

```
sf_commands_workspace_id_idempotency_key_key
route /api/connector/v1/commands/result
```

Пока каталог умещался в одну страницу, дефект был невидим. Прежнее доказательство «292/292 за 4 страницы» получено на харнессе, который строил все страницы из одного снимка, то есть живой путь «одна команда = одна страница» не проверяло.

## Исправление

- `ComputeCatalogId` считается только от канонически упорядоченного содержимого.
- Снимок строится один раз и кэшируется целиком - `ordered`, `pages`, `strategies`, `commission`, `generatedAt`, `catalogId`, `scannedTotal` - с TTL 10 минут. Все страницы доставки берутся из него, повторный запрос возвращает те же данные.

## Тесты

Регрессия закрывается на живом цикле через настоящие `_next_missing_catalog_page` и `_accept_runtime_catalog_page`, а не на заранее собранном снимке:

- 8 контрактов, 4 страницы - доставка сходится ровно за 4 раунда;
- при плавающей идентичности доставка не сходится, а рабочий каталог остаётся нетронутым;
- повторный запрос страницы не ломает staging;
- на исходнике моста закреплено отсутствие timestamp в идентичности и наличие кэша.

Полный набор: 2494 passed, 32 skipped.
