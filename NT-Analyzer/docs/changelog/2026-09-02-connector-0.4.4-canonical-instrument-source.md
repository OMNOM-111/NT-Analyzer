# Connector 0.4.4 - Canonical instrument source

Release summary: Каталог инструментов строится из собственной вселенной инструментов NinjaTrader, а не из кэша скачанных баров, поэтому корень виден в селекторе до первого бэктеста. `db\minute` остаётся признаком наличия локального кэша.
Release PRs: #271
Affected subsystems: Connector bridge (CatalogWriter)
Release impact: Connector-only. Backtest execution path, транспорт Connector, подпись и архитектура релиза не затронуты; серверный код не менялся.

## Где NinjaTrader на самом деле знает инструменты

В собственной базе `db\NinjaTrader.sqlite`: `MasterInstruments` (продукты) и `Instruments` (контракты с полем `Expiry`). Публичный доступ — `NinjaTrader.Cbi.MasterInstrument.All` и `NinjaTrader.Cbi.Instrument.All`; мост уже рефлектил в те же типы ради tick size и point value.

Эта база одинакова на обеих машинах: 365 фьючерсных корней и ~32k контрактов и на рабочей станции, и на сервере. `db\minute` же хранит только скачанные бары — 1547 инструментов локально против 16 на сервере.

## Что было не так

`ScanInstruments` перечисляет папки `db\minute`, и каталог наследовал это как источник истины о существовании инструмента. Инструмент, по которому историю ещё не качали, в списке отсутствовал, хотя NinjaTrader о нём знает и скачивает бары по требованию во время прогона Strategy Analyzer.

## Что вошло

- `CanonicalFutureFrontMonths` перечисляет `Instrument.All`, оставляет `InstrumentType == Future` и берёт по одному ближайшему неистёкшему контракту на корень, с `tick_size` / `point_value` из `MasterInstrument`.
- Эти строки добавляются к страницам каталога для корней, по которым нет кэша; корень с кэшем сохраняет свои строки и реальные диапазоны данных.
- `data_first` / `data_last` у канонической строки пусты — это и есть признак «локального кэша нет». Серверное правило `resolve_front_month` уже обрабатывает такой случай: без свежих баров выбирается ближайший неистёкший месяц по `expiry`.

## Бюджет транспорта

365 корней плюс кэшированные контракты - около 370 строк, примерно 5 страниц при потолке 16 страниц по 80 элементов. Транспорт не менялся.
