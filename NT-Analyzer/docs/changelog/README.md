# docs/changelog

Canonical home for release/change history and running integration logs
(e.g. `UI_INTEGRATION_LOG.md`). The repository `CHANGELOG.md` remains the
top-level release changelog; this directory holds longer-form running logs and
change narratives.

Governance amendment history is separate: it lives in the append-only
`data/governance/change_log.jsonl` and the rendered `docs/governance/OVERVIEW.md`
"Последние поправки" section.
