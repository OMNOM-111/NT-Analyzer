# Timeline: отдельная приёмка владельцем для задач текущего пакета

Release title: Owner approval workflow for the open Local delivery batch.

Change summary: В корневом `timeline.html` Local test и личное утверждение владельца стали разными статусами для каждой задачи. Описания объясняют назначение и результат функции. Текущий пакет остаётся закрытым для продвижения, пока каждая обязательная задача не пройдёт Local test и не получит явного решения владельца; затем действуют отдельные release/deployment gates.

Decision source: сообщение владельца в задаче 2026-09-24 и его отдельные ответы на уточнения в той же задаче. Это запись слов владельца, а не вывод из тестов или решение AI.

При уточнении владелец прямо указал: **пока лично утвердил только регистрацию**. Проверки SF Social, SF Chat, доверия устройству, общих моделей и Preview-графиков не превращаются от этого в Owner Approved. Отдельное слово «готово в Local» относится к техническому наличию и проверке. Счётчики сред не являются счётчиками личной приёмки.

Оперативные технические ограничения Agent World остаются в `NT-Analyzer/docs/current/AGENT_WORLD_MASTER_STATUS.md`; данная запись хранит **отдельно** замечание владельца о предстоящем осмотре. Вопрос о визуальном восприятии и чате пока не назван конкретным исправленным или воспроизведённым дефектом.

## Workflow и выпуск

Единое правило для всех AI-разработчиков: `NT-Analyzer/docs/TIMELINE_MAINTENANCE.md`; входные ссылки — корневые `AGENTS.md`, `CLAUDE.md`, `README.md`, документация governance и карта ролей. Перед задачей читать открытый пакет и нерешённые замечания; перед завершением обновлять evidence, комментарий владельца, timeline и handoff. AI не присваивает Owner Approved автоматически.

Текущий пакет: **1 из 7 задач утверждена владельцем, 6 из 7 имеют записанную Local-проверку; не готов к публикации.** Единый release artifact для этого batch ещё не собран; Canary и Production этот batch не получали. Последний записанный Production — Server beta.92; это не свежая проверка публичного endpoint. Одобрение функции не заменяет отдельное разрешение владельца на release/deployment и точный DEV → artifact → Canary → Production contract.

Affected surfaces: standalone owner timeline, mandatory maintenance workflow, developer entrypoints and Context Pack handoff. Application runtime, Git release artifact and server environments не изменены.
