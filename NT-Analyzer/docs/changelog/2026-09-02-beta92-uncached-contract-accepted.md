# beta.92 - Каталог принимает контракт без локального кэша

Release summary: Серверная проверка runtime-каталога считала голым корнем любой инструмент без диапазона данных и отклоняла весь снимок. Контракт определяется наличием контрактного месяца, а отсутствие диапазона означает лишь, что бары ещё не скачаны.
Release PRs: #273
Affected subsystems: connector protocol runtime catalog validation
Release impact: Разблокирует каталог из вселенной инструментов NinjaTrader (Connector 0.4.4). Backtest, транспорт Connector, подпись и архитектура релиза не затронуты.

## Что было не так

`_normalise_runtime_catalog` отвергал строку без `data_first`/`data_last`. Правило писалось тогда, когда каталог строился из `db\minute`, и там отсутствие диапазона действительно означало голый корень. Connector 0.4.4 берёт инструменты из `Instrument.All`, поэтому у ещё не скачанного контракта диапазона нет по определению - и каждая страница снимка отклонялась с `invalid_runtime_catalog`, а сервер продолжал жить на прежнем каталоге.

## Что вошло

Дискриминатор теперь тот же, что и всегда подразумевался: контрактом делает имя. `MNQ 09-26` - контракт независимо от кэша; `BTCUSD` контрактного месяца не имеет никогда и подтверждается диапазоном данных; `MNQ` без того и другого по-прежнему отклоняется.

## Проверено

Три теста закрепляют все три случая: некэшированный `6M 09-26` принимается, голый `MNQ` отклоняется, спот `BTCUSD` по-прежнему требует диапазон. Полный набор: 2490 passed, 32 skipped.
