# beta.95 - Единая Local-сборка: Social, Chat, вход и безопасность вместе

Release summary: Завершённые направления собраны в одну Local-версию: новый вход и регистрация, подтверждение устройства, owner Preview, SF Social и SF Chat работают в одном продукте с общей идентичностью пользователя.

Release PRs: #270 #278 #279
Affected subsystems: auth account community sf-chat ui preview
Release impact: Только Local/Development. Canary и Production не изменялись, deploy не выполнялся. Это интеграционная сборка для финальной проверки владельцем.

## Коротко

- Один Local вместо трёх отдельных веток: Social, Chat, вход, безопасность и Preview в одной версии.
- Имя пользователя, выбранное при регистрации, проходит через профиль, SF Social и SF Chat как одна идентичность.
- Ни одна завершённая функция не потеряна при слиянии: общие файлы объединены содержательно, а не выбором одной стороны.

## Что вошло

**SF Social и SF Chat** из `codex/community-social-network` (PR #270) — уже находились в `main`: постоянная запись, раскрытое аудируемое удаление, страница компании, разделение уведомлений и мессенджера.

**Device Confirmation / Trusted Access** из `codex/device-confirmation-trusted-access` (PR #278): pending-сессия на пять минут, OTP через подтверждённый Telegram или e-mail, постоянное доверие либо доступ только до конца сессии, Machine → Client → Session только при доказанной привязке.

**Owner Preview / Synthetic User Sandbox** (тот же PR): отдельный loopback-процесс с собственным data root, cookie namespace и synthetic identity, где владелец проходит продукт глазами обычного пользователя.

**Login / Registration** из `codex/auth-onboarding-redesign` (PR #279): Welcome с одним выбором, отдельный экран входа с быстрым входом по QR, регистрация в три шага, имя пользователя StratForge независимо от Google и Telegram, согласие с условиями на последнем шаге.

## Разрешение конфликтов

`VERSION.json` не получил ни одну из сторон: интеграционная сборка взяла следующий свободный номер. В `UI_API_MAP.md` переписанная строка auth заменила только старую строку auth, а обе строки SF Chat и оба списка контрактов сохранены. В `02`, `11` и `12` External GPT Context записи обоих направлений разработки сохранены, потому что в единой сборке существуют оба. `server.py`, `ui.js`, `theme.css`, `api.js` и `test_aurora_contracts.py` слились автоматически и были проверены на присутствие обеих функциональностей.

## Проверено

Полная регрессия на интеграционной ветке, статические проверки, pre-release gate и браузерный проход в единой сборке: регистрация нового пользователя от Welcome до Dashboard, его профиль в SF Social, переход в SF Chat, вход существующего пользователя, неизвестный клиент, доступ только до конца сессии, owner Preview и обход всех разделов.

## Почему версия поднята

Environment Switcher берёт описание среды из `docs/changelog/*-beta<N>-*.md`, совпадающего с номером beta работающей сборки. Интеграция — это отдельная сборка, поэтому карточка DEVELOPMENT должна описывать именно её, а не одну из объединённых веток.
