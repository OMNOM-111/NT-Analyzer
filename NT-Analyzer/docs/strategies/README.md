# docs/strategies

Canonical home for strategy documentation: lifecycle, quality gates, recovery,
run controls and the strategy risk profile (e.g. `STRATEGY_LIFECYCLE.md`,
`AI_STRATEGY_LAB_QUALITY.md`, `risk-profile.md`).

New strategy docs are created here. Existing strategy docs currently remain at the
`docs/` root; they move here in owner-approved steps per the migration map in
`docs/DOCS_STRUCTURE.md`. Strategy specs never define global governance or safety
limits — those live only in `data/governance/*` and are owner-gated.
