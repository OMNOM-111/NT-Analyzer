# docs/agents

Canonical home for AI agent documentation: agent roles, personas, dialogue
contracts and the orchestrator (e.g. `AGENT_PERSONAS.md`, `AI_DIALOGUE_CONTRACT.md`,
`CHIEF_AI_AGENT.md`, `VITEK.md`).

New agent docs are created here. Existing agent docs currently remain at the
`docs/` root; they move here in owner-approved steps per the migration map in
`docs/DOCS_STRUCTURE.md` (each move rewrites its inbound links so nothing breaks).

Shared model access (who may call whose connection, the share switch and the
call ledger): `SHARED_MODELS.md`.
