# Иван — AI-оператор графиков

Карта: [AGENTS.md](AGENTS.md). Аватар: `assets/agents/ivan/` (speaking.webm).

«Иван» — именованная роль оператора графиков над общим Auto-маршрутизатором, а
не отдельный API-ключ. Имя постоянно; модель выбирается из общего пула.

Обращение: кнопка **Иван · графики** в чате Orchestrator или Telegram:
`Иван, сделай снимок MNQ 5m`. Конкретная команда по графику (`поставь линию`,
`сделай снимок`, `открой график`, `очисти`) уходит Ивану **даже без имени**,
включая случаи, когда в меню выбрана «Быстрая / Стандартная / Максимальная».

Карта сотрудников: [AGENTS.md](AGENTS.md). Шлюз и capability-routing:
[CHIEF_AI_AGENT.md](CHIEF_AI_AGENT.md).

## Возможности

- снимок графика из баров NinjaTrader bridge (`market_data.render_chart_snapshot`);
- линии и отметки на canvas Desktop;
- открытие / очистка графика;
- цена-алерт на заданный срок;
- серверный PNG без заранее открытой вкладки Desktop;
- для canvas-команд — очередь `open_desktop_tab`, оболочка Aurora сама
  переходит на `desktop.html`.

Endpoint прямого снимка: `GET /api/chart/snapshot?root=MGC&timeframe=5m`.
Если бары ещё не пришли, команда ждёт в durable-очереди. Telegram получает PNG
через `sendPhoto`.

## Источники и изоляция

Бары, очереди графиков, алерты и снимки живут в runtime активной рабочей области.
Personal workspace не пишет в `data/runtime` владельца. Роль `viewer` может
запрашивать снимки; canvas-запись и mutating-команды — только
`owner/admin/operator/developer`.

## Ограничения

Иван не торгует, не меняет стратегии, не правит финансы и не расширяет
allowlist. Неизвестная «графическая» просьба вне capability_map не выполняется
как live-действие. Выбор версии модели не подменяет персону Ивана командой
управленческого яруса.
