# Общие модели (shared models)

Актуально на 2026-09-22.

Базовый контракт общего доступа к подключённым моделям. Тарифов, кнопок выдачи
моделей и квот на пользователя здесь нет — это отдельный этап.

## Владение и использование — разные вещи

| | Владелец подключения | Другой пользователь |
|---|---|---|
| API-ключ, endpoint, учётная запись провайдера | хранит, никому не показывается | не получает никогда |
| Persona, к которой привязано подключение, проверки соединения | свои | не видит, не заимствует |
| Вызов модели | всегда | только пока включено «Поделиться» |
| Свои чаты, память, задачи, история | свои | свои; чужие не видны ни в одну сторону |
| Статистика | свои запросы + отдельно «Использование другими» | свои вызовы через общую модель |

## Переключатель «Поделиться»

- У каждой своей модели в карточке (AI Центр → Модели → модель) — один переключатель.
- Включён: другие пользователи видят модель как **общую** (только название, провайдер,
  имя модели) и могут её вызывать.
- Выключен: модель доступна только владельцу. Выключение запрещает **следующий** чужой
  вызов — новый запуск, уже стоящий в очереди и даже вызов между допуском и отправкой.
  История (задачи вызывающего, журнал вызовов, события включения/выключения) не удаляется.
- Отключение подключения («Отключить») автоматически закрывает общий доступ.
- Делиться можно только активным подключением модели; внешних агентов — нельзя.

## Как работает вызов через общую модель

- Задача, чат и история живут в пространстве **вызывающего**. У него создаётся
  собственная запись общей модели со своим id; id подключения владельца он не знает.
- Исполнитель читает подключение владельца только в момент вызова и перед каждой
  отправкой перепроверяет грант.
- Через общую модель выполняются только прямые запросы (ответ помощника, проверочные
  задания). Проверка соединения, судейство, маршрутизация, цепочки и планы приложений —
  только на своих подключениях.
- Нужен доступ к AI (`ai_lab`), а не право подключать свои модели (`ai_pro_models`).
  Бюджет AI рабочего пространства вызывающего и лимиты самого подключения владельца
  (дневной/месячный) действуют как обычно; лимиты подключения считают расход всех,
  кто через него вызывал.
- В чате: если у выбранной Persona нет своего подключения, говорит первая доступная
  общая модель; в списке «Подключение» общие модели помечены «· общая».
- Реестр моделей владельца (Local): запрос от имени любого пользователя, кроме
  владельца, может использовать только модели, привязанные к расшаренным подключениям.
  Это касается и старого оркестратора чата. Фоновая работа платформы без пользователя
  работает как раньше. Правило действует только в Development (Local): Canary и
  Production остаются со своими бюджетами и распределением, пока владелец не решит иначе.

## Журнал вызовов

Каждый вызов через чужое подключение — одна строка: кто вызвал, чья модель, какая,
задача/тема, агент, назначение, статус, токены вход/выход, стоимость (неизвестная
стоимость не превращается в ноль). Промптов и ответов в журнале нет.

- Владелец: «Использование другими» в карточке модели — по людям, отдельно от своих запросов.
- Вызывающий: «Ваши вызовы через общую модель».

Хранилище: `data/ai_control_center/model_sharing.sqlite3` (Local, Development).
Код: `app/ai_control_center/model_sharing.py`, `ModelService.set_sharing`,
`ModelExecutor(shared=...)`, проверка в `universal_llm.invoke_agent` и `agent_router.candidates`.
Тесты: `tests/test_agent_world_shared_models.py`.

## Ограничение Local

Agent World на Local открыт только для рабочих пространств из
`STRATFORGE_AGENT_WORLD_LOCAL_WORKSPACES`. Пользователь вне этого списка работает с
общими моделями через AI Чат, но не через Agent World, пока оператор не добавит его
пространство.
