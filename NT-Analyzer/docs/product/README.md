# docs/product

Canonical home for product documentation: product modes and contours, UI parity
and verification matrices and visual acceptance (e.g. `UI_PARITY_MATRIX.md`,
`UI_VERIFICATION.md`, `MARKET_DATA_VISUAL_ACCEPTANCE.md`).

`PERMANENT_RECORD.md` states the platform's central product rule: what is
published in SF Chat cannot be deleted or edited, by the author or the owner.
It is enforced in `app/community.py` and is the canonical wording for it.

`AI_CENTER_OWNER_RULES.md` records the owner's rules for the AI Center (first
visit, connecting a model, shared owner model, agent hierarchy, goals, the agent
world screen). Any of them changes only after the owner confirms it.

New product docs are created here. Existing product docs currently remain at the
`docs/` root; they move here in owner-approved steps per the migration map in
`docs/DOCS_STRUCTURE.md`.
