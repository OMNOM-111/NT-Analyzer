# docs/security

Canonical home for security documentation: environment isolation, authentication
and identity, step-up challenges, trusted devices and the resilience/security
backlog (still-current items extracted from dated snapshots).

New security docs are created here. Existing security material currently remains
at the `docs/` root or in `docs/current/` phase evidence; it moves here in
owner-approved steps per the migration map in `docs/DOCS_STRUCTURE.md`.
