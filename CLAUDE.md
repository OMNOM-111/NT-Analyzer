# Claude development entrypoint

Before starting or handing off any development task, follow the mandatory [timeline and owner-approval workflow](NT-Analyzer/docs/TIMELINE_MAINTENANCE.md) and repository [rules](AGENTS.md). Read the root [product timeline](timeline.html), [AI_CONTEXT index](AI_CONTEXT/00_STRATFORGE_CONTEXT_INDEX.md), [current state](AI_CONTEXT/02_CURRENT_SYSTEM_STATE.md) and [active handoff](AI_CONTEXT/11_ACTIVE_WORK_AND_HANDOFF.md). Continue unresolved owner comments. Completion order is code/config/action → test → Timeline sync → AI_CONTEXT sync → validation → final response, with the canonical changelog updated as needed. Local test PASS never grants Owner Approved.
